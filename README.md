# SentimentSense

SentimentSense is an AI-powered web application that performs **Sentiment Analysis** and **Sarcasm Detection** on textual data. Unlike conventional sentiment analysis systems that classify text solely as positive, negative, or neutral, SentimentSense understands contextual cues and identifies sarcastic expressions that often reverse the intended meaning of a sentence.

The application leverages modern **Natural Language Processing (NLP)** and **Machine Learning** techniques to provide accurate sentiment classification and sarcasm detection. It is designed to analyze text from social media comments, customer reviews, online discussions, and other user-generated content.

---

## Features

-  **Sentiment Analysis**
  - Classifies text into Positive, Negative, or Neutral sentiments.

-  **Sarcasm Detection**
  - Identifies sarcastic and non-sarcastic statements using contextual understanding.

-  **Interactive Dashboard**
  - User-friendly web interface built with Streamlit.
  - Displays prediction results in an intuitive format.

-  **Text Analysis**
  - Analyze individual sentences or paragraphs.
  - Suitable for social media comments, reviews, and textual feedback.

-  **Real-Time Prediction**
  - Instant analysis with minimal processing time.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/SentimentSense.git
cd SentimentSense
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

### 3. Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
streamlit run App/main.py
```

The application will launch in your default browser.
